# Museum Companion — Meta Ray-Ban Display 博物馆导览

文档版本：v0.1 · 2026-11-14（Europe/Helsinki）

让参观者佩戴眼镜听作品讲解，在现实作品上定位并持续跟随细节，放大观察，并随时打断追问。

## 当前阶段

已完成两轮产品访谈和第一版产品／技术文档。按用户最新安排，**先完成文档，再选择 iPhone 或 Android；本轮未进入应用开发**。

以下材料描述需求、建议方案和验收方式，不代表已经实现或通过真机测试。最大的未决条件是：公开 SDK 能否支持足够低延迟的显示更新，以及相机到佩戴者视野的校准能否让框稳定对准现实细节。A 版仍是核心需求，不以相机画面内的框替代验收。
