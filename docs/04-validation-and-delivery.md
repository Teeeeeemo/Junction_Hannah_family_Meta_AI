## 1. 阶段安排

已完成的工作是产品访谈、PRD、技术设计和平台调研。后续顺序：

1. 先准备模拟器原型的相机／视频、音频和显示适配，不把环境背景误当作应用的相机输入。
2. 一幅作品端到端实现“通识语音介绍 → 自动识别细节点 → 右侧编号列表 → 自动 1 号讲解 → 用户打断改选”；两种讲解均测持续追踪。
3. 扩展到建议的三幅，执行自动化检查、模拟器和云 API 联调。
4. 确定手机主平台并取得眼镜后，运行官方示例、Gate 0 和真机验收；当前没有硬件，这部分不能判定通过。
5. 分阶段提供源码、运行说明、原型证据和限制；最终设备构建产物与真机报告单列。

Codex 负责应用与后端实现、测试设计、可自动执行的检查和交付材料。后续实体设备可用时，用户完成持有人必须操作的配对与授权，并反馈实际佩戴对齐。没有设备不会阻止模拟器原型开发，但真实 A 版验收仍保留为待执行，不能从模拟结果推断通过。

| 测试 | 对应验收 | 操作与预期 |

| T01 作品识别 | A01 | 3 幅画各 10 次；包含正视、轻微斜视、距离变化；总成功率 ≥90% |
| T02 陌生与相似作品 | A01 | 10 次库外作品测试，不误触发为库内确定作品；相似候选先澄清 |
| T03 固定细节几何 | A02–A03 | 合成已知透视与遮挡；比较标注角点与预测角点，不只看框是否出现 |
| T04 现实光学对齐 | A02–A03 | 佩戴者观察真实目标；静止、转头、平移、改变距离分组记录；屏幕内框不代替 |

| T09 正常语音打断 | A06 | 在通识介绍、自动讲解、用户选点讲解、回答时分别起声；旧音频及时停止，旧轮次迟到音频不重播，自动推进暂停 |

| T19 手机后台／锁屏 | 体验目标 | 分别记录采集、显示、播放和恢复状态；未通过时说明演示操作条件 |
| T20 会话结束 | A10 | 停止后不继续播放／上传／占用相机，重复开始可用 |
| T21 自动进入与首点 | A11 | 通识介绍完成和跳过分别测试：无需再次操作便进入细节模式；右侧列表就绪后只自动启动一次 1 号，确认定位再讲解并持续框选 |
| T22 自动点位发现 | A12 | 用不同作品、区域遮挡和空白画面验证；点位确实来自当前输入，无可靠候选不凑固定清单、不生成无依据解释 |
| T23 稳定编号 | A11–A12 | 头部／视频移动、遮挡、恢复、换语言不重排旧编号；新增点追加；换作品后拒绝旧列表选点请求 |
| T24 打断改选与同步 | A02、A06、A11 | 自动讲 1 号时说“讲第 3 个”，以及列表导航确认；旧讲解中止，列表高亮、音频、框和局部窗均对应 3 号并持续追踪 |
| T25 无效／不可见点位 | A04、A06、A12 | 无效编号先澄清；所选点离开画面时提示并隐藏无效框；不把其他点改成该编号，不沿用上一点的框 |
| T26 用户选择优先 | A06、A11 | 在默认首点任务／下一点任务／旧识别任务返回前改选；迟到任务不覆盖 selection_version，不出现选 3 号后又自动跳回 1 号 |

## 6. 指标如何测量

### 6.1 现实框

至少记录 3 个观看位置、5 个静止验证点和 3 组缓慢移动。拍摄目标与实际叠加框的可比较证据；能通过镜片拍摄时用相应装置，无法时记录佩戴者逐点对齐判断与测量限制。

角度误差优先使用经确认的显示视场／校准模型换算。无法可靠测角时，应报告显示坐标误差和佩戴者结果，并把 PRD 的角度指标保留为未完成测量；不能假设线性像素缩放便是人眼角度。

### 6.2 延迟与百分位

每个有效样本记录起点、终点和测量时钟。云端不同机器的原始时钟不能直接相减；用户发声到耳边停止可通过同一录音／外部测量比较。端侧起声检测至 stop 调用时间只能作为软件指标。

按升序样本的 nearest-rank 方式报告 p95，并同时记录样本数、场景和失败次数。中英各至少 20 次打断／回答测量；少样本的百分位是初步证据，不是大规模用户统计。

### 6.3 内容审核

整理“讲解句／claim_id → source_id → 网页段落或馆藏字段”的审查表。事实、观察和解释分开核对。测试至少包含一个有争议问题和一个资料不足问题。

## 7. 两分钟演示脚本草案

| 时间 | 用户动作 | 展示的价值 |
|---|---|---|
| 0–20 秒 | 输入首幅画，自动开始通识介绍 | 先听懂整件作品 |
| 20–45 秒 | 介绍结束，自动识别细节点并生成右侧列表，从 1 号开始；移动测试画面 | 无需点击进入模式；1 号持续框选追踪 |
| 45–65 秒 | 用户选择 2×，再选择 4× | 右上角局部放大，列表仍可选择 |
| 65–95 秒 | 打断说“讲第 3 个”，再追问背景 | 列表、语音、框与局部窗同步切到 3 号并持续追踪 |
| 95–110 秒 | 问出处并切换语言 | 可信资料与双语 |
| 110–120 秒 | 继续或结束 | 保持个人节奏与完整闭环 |

当前脚本先在模拟器运行，电脑相机／视频输入与电脑音频明确标注。脚本不是验收证据。最终取得设备后的实际眼镜显示、手机调试视图、模拟器效果应分开标识。
