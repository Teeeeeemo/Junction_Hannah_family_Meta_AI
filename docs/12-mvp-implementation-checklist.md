**2026-11-15 用户实测更正：iOS 0.2.2 / build 6 已安装并打开，但用户反馈手机应用没有二维追踪框。该功能按“手机端未实现可用效果／待修复、未验收”管理；已有 Vision 代码、合成图像或模拟器测试不能证明手机功能可用，具体失败环节尚待复现。镜片现实跟随框及光学标定也未完成。**

**当前产品规则（2026-11-15 用户确认）：** 允许同时生成概览与细节点，也允许在概览生成、朗读期间识别细节；概览结束或跳过后才在眼镜 Display 右侧展示细节列表并自动进入 1 号。失跟只隐藏无效框和局部窗，正在进行的讲解继续；新点最多等待约 2.5 秒定位，超时仍讲解，可靠定位恢复后再显示框和局部窗。用户暂停、打断、结束仍须生效；无可靠作品／细节点时不得凭空讲解。这是正式需求，不再记为偏离 PRD。

- [ ] 手机二维追踪框：真实手机相机与视频各验证自动首点、改选、移动／缩放、失跟清框与恢复；当前用户验收未通过。
- [ ] 列表时序：允许提前生成，概览结束／跳过前不在 Display 展示，之后列表就绪才自动首点。
- [ ] 连续性回归：失跟不打断讲解；新点最多约 2.5 秒后开讲；手动暂停不被重定位恢复覆盖。
