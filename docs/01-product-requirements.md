1. **手机图像内跟随框：** 用可重放二维画作视频复现，再在手机相机验证；打通细节坐标、追踪、选点与预览绘框。处理图像方向、等比显示留白、移动／缩放／透视变化和失跟恢复；显示当前定位状态及无框原因。自动首点和用户改选均须有可见证据。

## 1. 产品定位

为佩戴 Meta Ray-Ban Display 的成人博物馆参观者提供第一视角的个人导览：识别作品、播放讲解、指出正在讲解的现实细节、放大观察，并围绕用户感兴趣的内容继续对话。

核心体验用一句话表达：**听懂整件作品，看清具体细节，随时问下去。**

### 1.1 问题与用户

访谈中提出的痛点是：缺少艺术背景的参观者难以理解作品的创作背景和细节含义；团体导览不易照顾个人节奏；常规录音讲解缺少针对细节的互动。这些是当前产品假设，尚未经过独立访客研究。

初始目标用户包括学生、工作人群和老年参观者。48 小时演示先验证共同需求：无需拿出手机，能够听懂、定位、放大和追问。不同年龄的可用性不能仅靠一次演示得出结论。

### 1.2 现有产品的借鉴范围

[Smartify](https://smartify.org/) 提供面向艺术与文化场所的内容探索；[Bloomberg Connects](https://www.bloombergconnects.org/) 提供机构策划的音视频导览，并介绍了字幕、图像放大等可访问性功能。可借鉴短讲解、深入内容和便捷播放的组织方式。

本项目自行实现交互，使用经确认可用的作品图像与资料；现有产品未被证明具备本项目要求的现实跟随框，不以其宣传作为技术依据。

## 3. 第一版建议范围

建议从 **3 幅预先准备的二维画作，每幅目标识别约 3 个细节点**开始。细节数量是演示建议，不是必须填满的固定列表；实际只列出来自当前作品、已识别且具有有效区域的点位；暂时无法追踪的点保留编号并标记定位状态。优先把一幅画从通识介绍、自动选点到打断切换完整跑通，再扩展到其余两幅。作品数量和展陈方式仍待最终选定。

建议演示条件：固定展板上的打印复制品，或固定屏幕上的画作；光线稳定；有网络；有可用于校准的观看距离。它们是控制演示风险的建议条件，不代表产品只适用于复制品。

第一版提供：开始／结束导览、通识语音介绍、自动进入细节模式、自动生成右侧编号列表、从 1 号点位开始讲解、打断并选点、跟随框、1×／2×／4×、暂停／继续、语音追问、中英切换、来源查看。头部对准选择可以保留为辅助入口，列表／语音选点是主流程。

当前没有实体眼镜，可先在官方模拟器中验证流程、列表与视频内追踪，并通过电脑音频测试讲解和打断；这些结果与最终真机现实对齐分别验收。

第一版不安排账号系统、付费、室内导航、博物馆全量内容、无限作品识别或多人协作。3D 示例在 P0 全部通过后安排。上述后续方向不影响已确认的核心体验。

## 4. 核心用户流程

### 4.1 开始与通识语音介绍

1. 用户选择讲解语言。真机使用前完成配对、权限和必要的显示校准；模拟器原型明确标注电脑摄像头／视频与麦克风来源。
2. 开始导览后，当已支持作品稳定出现时，首先进行通识语音介绍，说明作品身份、创作背景和总体看点。
3. 建议介绍长度 20–40 秒，可暂停、跳过，或直接问问题。介绍完成或用户选择跳过后，自动进入细节模式，不要求再次点击“进入细节”。
4. 未识别到作品时提示重新对准；不得把模糊候选当成确定识别结果。

### 4.2 自动进入细节模式并生成右侧列表

1. 系统可一次生成概览和细节点，也可在概览生成或朗读期间并行识别当前作品的可讲解细节；无需等待概览结束才发起识别。列表加载并校验完成即在眼镜 Display 展开，概览正在朗读也不隐藏列表。
2. 列表就绪立即展示；未就绪显示识别进度。展示列表本身不打断概览、不提前自动讲 1 号；概览结束／跳过且列表就绪后才自动进入 1 号。概览期间用户主动选点则立即中断概览并讲所选点，不再自动回到 1 号。在眼镜屏幕右侧统一显示“编号 + 简短名称 + 状态”，例如“1 柏树、2 云层、3 麦田”。每项标题最多三个单词，编号不计入词数；编号与实际识别结果绑定，不是预先摆放的固定菜单。
3. 为本次作品会话固定编号与顺序；头部移动、暂时遮挡或重识别不能让同一个点位突然变号。切换作品后建立新列表。
4. 识别失败或没有可靠点位时，显示“正在识别／请重新对准”等状态，不编造列表或讲解。已确认细节点暂时失跟与未识别出可靠细节点分别处理，前者按讲解连续性规则执行。
5. 预标注可以辅助几何校验和演示准备，但不能用未经画面识别的固定列表代替“自动识别细节点”。历史背景和出处仍受可靠资料约束。

### 4.3 默认从 1 号点位开始讲解，并允许打断改选

1. 概览结束／跳过且列表就绪、用户尚未主动改选时，系统默认选择 1 号点位并请求定位，不要求用户先点击 1 号。可靠定位成功即开讲；否则最多等待约 2.5 秒仍开始讲解，同时提示正在定位。
2. 只有当前点可靠定位时才显示检测框及局部窗；框住同一现实细节并持续追踪。定位暂不可用不阻止讲解，右侧仍高亮正在讲解的编号，不展示陈旧框或伪造位置。
3. 用户可以随时说“讲第 3 个／Tell me about point three”，按名称选点，或用方向导航选择列表项并确认。选点立即中断旧讲解和自动推进，切换到新点位。
4. 切换后列表高亮、检测框、讲解与放大窗必须对应同一细节点；不能一边讲 3 号、一边仍框着 1 号。新目标尚不可定位时提示重新对准，不沿用旧框；同样执行最多约 2.5 秒等待后开讲的规则。
5. 默认顺序建议按 1→2→3 逐点讲解；暂停、用户发言和问答期间不自动切点。用户选点后保留该点，后续“继续”从当前点恢复，“下一个”按原编号选择下一个尚未讲完的点；不自动回到 1 号。
6. 原有头部对准选择可以作为辅助方式，不要求用户必须移动头部才能通过右侧列表改选；不宣称读取眼球注视位置。

自动讲解与用户选点讲解都执行同一套检测框和持续追踪规则。点位暂时离开可显示区域时提供方向提示；失跟后隐藏无效框和局部窗，正在进行的讲解继续；恢复可靠定位后再显示当前点的框与局部窗，不重播已讲段落，不解除用户手动暂停。

### 4.4 放大观察

1. 锁定细节后，用户选择 2×或 4×，或说“放大两倍／Zoom in four times”。
2. 右上角出现以当前细节为中心的局部图像；框仍标记现实作品中的位置。
3. 该窗口宽度为可用显示区域 W 的 1/2，高度为 H 的 1/2，即面积约为整个显示区域的 1/4。安全边距可在真机调试时微调。
4. 放大只影响窗口中的图像，不会把现实作品本身放大。
5. 2×／4×是同一基础取景范围的线性数字放大；不把数字插值描述为恢复了原图中不存在的笔触。
6. 用户可返回 1×或关闭窗口；切换语言、倍率不会改变已选细节。
7. 新增右侧列表与原有右上角放大窗同时保留：建议未放大时列表在右侧显示，放大时右上为局部窗、右下为可滚动列表。列表不遮住放大窗；此布局是实现建议，需在模拟器检查可读性。

### 4.5 随时打断与追问

用户在讲解中问：“为什么他戴着这条链子？”／“Why is he wearing that chain?”

系统停止当前音频并暂停自动切点，保留作品、点位编号和细节上下文。普通追问围绕当前点位回答，回答后等待“继续／Continue”，从当前点的合适句子或段落恢复；选点指令则直接切换并讲解所选点位，不重播通识介绍或自动回到 1 号。

“讲第 N 个”“讲这个名称的细节”“停止”“暂停”“继续”“下一个细节”“两倍”“四倍”“切换中文／English”“来源是什么”应形成固定、可测试的指令集。不存在的编号、声音含混或指代不明时先澄清，不随意换目标。

### 4.6 每段独立环形朗读倒计时（新增，待实现）

- 在当前朗读段旁展示一个环形倒计时及剩余时长；概览是一段，每个细节点各是一段，不共用整场导览倒计时。环从满逐渐减少，概览切细节、自动下一点、手动改选或从头重播都重新开始当前段计时。
- 计时从音频实际开始播放时启动；连接、生成、缓冲、定位等待不消耗朗读时间。暂停冻结，继续从当前进度接续；打断／追问时停住原段，返回该段继续时按实际恢复位置计时。回答不能误推进原段环。
- 0.75×–2×倍速改变后按剩余音频重新计算预计时长；取消旧段时旧音频回调不能改写新段倒计时。
- 流式音频未生成完时无法知道精确总时长：必须标注“预计剩余”，估算依据随实际音频更新；没有可信估计时显示待估算／生成状态，不虚构精确秒数或假装已播完。音频真正播放完成才归零并推进下一段。
- 眼镜 Display 与手机当前朗读卡片同步状态，环不能遮挡作品、字幕或细节列表。具体布局由实现适配，真实眼镜可读性另行验收。

### 4.7 细节标题最多三个单词（新增，待实现）

- 限制的是细节列表每项标题，不截短讲解正文、作品名或来源。英文最多三个以空白分隔的单词，编号不计入；例如 `Folded Hands`、`Distant Mountain Path`。
- 中文使用简短词组，不把整句无空格文本当作一个词规避限制。实现约定：使用支持中文的分词器按最多三个词校验，保留明确的目标名；分词规则写入回归样例。此为三词限制的中文技术解释，并非额外的已确认字符上限。
- 生成和翻译后均校验，超限优先改写为语义完整的短标题；不能仅靠 UI 截断掩盖超限。另保留屏幕宽度保护和可读性检查。
- 短标题与完整名称、别名和稳定 detail_id 分开保存；缩短或翻译标题不得重排编号，不能让“讲第 3 个”选错点。

## 5. 显示与交互规则

| 状态 | 显示 | 音频与操作 |
|---|---|---|
| 正在识别 | 简短状态，不显示确定框 | 可取消 |
| 通识介绍 | 名称、当前概览环形倒计时；细节列表就绪即显示 | 不因列表出现中断概览；用户可直接选点打断；否则完成／跳过后自动首点 |
| 细节点识别 | 未就绪显示识别进度；可靠结果固定编号并立即显示 | 不虚构细节点；已确认点位按最多约 2.5 秒定位等待规则开讲 |
| 默认自动讲解 | 右侧列表高亮 1 号起的当前点 + 该点持续跟随框 | 自动开始；允许打断改选 |
| 用户选点讲解 | 右侧列表高亮新点 + 同一新点持续跟随框 | 立即中断旧讲解并讲解新点 |
| 放大 | 跟随框 + 右上角局部窗／倍率 + 右下方列表 | 可切换倍率、关闭、改选、追问 |
| 用户发言 | 保留列表与当前点编号，显示“正在听”；可靠时继续追踪 | 立即停止旧讲解，暂停自动推进 |
| 失去追踪 | 隐藏失效框及局部窗，保留编号并标记暂不可见 | 当前讲解继续；定位恢复后恢复视觉，不自动解除手动暂停 |
| 查看来源 | 简短来源标题／机构，可分页 | 完整链接可在配套 App 中查看 |
| 断网 | 明确提示连接状态 | 若已缓存可继续固定内容；实时问答不可冒充在线 |

视觉以细框和短文本为主。跟随框不长时间遮挡细节；框与放大窗重叠时优先保证框的可辨认性。目标位于可显示视野之外时，只提供方向提示或请用户转头，不把框挤到错误位置。

眼镜为透视显示，黑色区域不能当作能遮挡现实背景的黑色屏幕；放大窗对比度和可读性需要真机检查。

手势方案优先采用设备已有的确认／方向导航交互；具体映射待主平台和权限验证后确定。语音追问是核心需求，按钮中断是辅助入口，不能代替自然语音打断通过验收。

## 6. 内容与事实要求

每件作品至少包含：作品名、作者、年代、馆藏来源、通识介绍、已识别细节点的稳定 ID／会话编号／名称／位置／可见状态、细节解释、资料引用和中英文本。点位编号是交互标识，不能直接替代跨帧稳定 ID。

内容分为三类：

- **可核实事实**：作者、年代、材料、可追溯的历史背景。
- **视觉观察**：画面里可见的物体、颜色、位置和线条。
- **解释／学术观点**：注明依据；存在争议时说明是解释，不说成唯一事实。

每个背景或象征意义的讲解单元应绑定资料 ID。模型可以改写语言和回答方式，但不能自行生成并不存在的馆方出处。没有资料支持的问题，应明确说明现有材料不足。

用户说“出处”时默认解释当前讲解依据；若问题指向藏品流传记录（provenance），则单独回答，不与资料引用混淆。

默认保持当前语言；用户明确要求切换时生效，也可用另一语言提问并获得相应语言回答。作品身份、已选细节和倍率在切换时保留。多语扩展采用语言字段，不在业务逻辑中写死中文／英文判断。

## 7. 验收目标

以下均为**拟定目标，尚非实测结果**。详细测量方式见[测试与交付计划](04-validation-and-delivery.md)。

| ID | 验收项目 | 建议标准 |
|---|---|---|
| A01 | 识别 | 3 件已登记作品各 10 次测试，总成功率 ≥90%；陌生作品 10 次均不自动确认为库内作品 |
| A02 | 现实跟随框 | 默认自动讲解和用户打断选点两种流程，框均持续对准当前真实细节；列表高亮、音频与框一致；画面内框不代替真机验收 |
| A03 | 跟随质量 | 稳定追踪段视觉更新 ≥10 Hz；端到端延迟 p95 ≤200 ms；静止角点误差 p95 ≤1°、缓慢移动 ≤2°，并通过佩戴者观察验证 |
| A04 | 失跟与讲解连续性 | 失跟或校准无效后目标 ≤300 ms 隐藏框及局部窗，当前讲解继续；新点定位等待最多约 2.5 秒后开讲；可靠追踪恢复后再显示，手动暂停仍有效 |
| A05 | 放大 | 1×／2×／4×切换正确；右上角窗口尺寸符合暂定布局；同一细节在轻微移动后保持居中 |
| A06 | 打断与切点 | 用户起声至耳边旧音频停止 p95 ≤500 ms；选第 N 点后列表、音频、框与放大窗切到同一新点；旧队列和自动推进不覆盖用户选择 |
| A07 | 回答 | 现场网络下，从用户结束发言到首段回答音频 p95 ≤3 秒，较慢时有等待反馈 |
| A08 | 双语 | 中英分别完成概览、细节讲解、打断、追问、继续、倍率与来源操作 |
| A09 | 可追溯 | 演示内容中的背景性事实均可映射到资料；无根据问题明确说明不足 |
| A10 | 稳定性 | 连续 10 分钟完整导览无崩溃／持续断连；一次短暂失跟和一次断网可恢复 |
| A11 | 自动流程与右侧列表 | 通识介绍完成／跳过后无额外确认进入细节模式；细节列表就绪立即显示且不自动打断概览，用户可主动选点；概览结束时列表未就绪则等待可靠结果；无需点击便从 1 号开始，定位等待按 A04；移动、失跟恢复与中英切换不改变既有编号 |
| A12 | 点位识别可靠性 | 画面变化时验证候选确实来自当前作品；无可靠候选时不虚构点位；列表项有名称和可定位区域，语音编号与稳定 ID 映射正确 |
| A13 | 分段环形朗读倒计时 | 概览、细节 1、细节 2 各自计时；切段／重播重置；暂停冻结、继续接续、倍速调整剩余时间；流式估时明确标注，最终完成以实际音频播完为准 |
| A14 | 三词标题 | 细节列表每项最多三个单词，编号不计入；中英切换、生成、翻译、分页和重识别后仍满足；标题不改变 ID、编号或语音选点映射 |

角度阈值和显示更新目标需要 Gate 0 先验证可测、可达；任何修改应写入版本记录，而不是把不通过改写为通过。UI 响应、相机帧率与实际显示更新率要分别测量。
