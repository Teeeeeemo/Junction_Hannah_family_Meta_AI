# Simulator MVP：运行与验收记录

日期：2026-11-14（Europe/Helsinki）  
实现范围：一幅画的本地 Simulator MVP。最终真机要求仍参照 PRD v0.2。

## 1. 本次实现

- 内置 The Met 公开画作《Wheat Field with Cypresses》及馆方来源。
- 默认改为实时相机输入，内置画作改为手动选择；无真实解码帧时不提交识别。眼镜 Web 的相机权限限制由 iOS DAT 接入阶段解决。
- 真实 Gemini 图像分析、3–5 个细节点候选（不足时不补预设点）、通识介绍与细节文本。
- 介绍结束后自动显示右侧稳定编号列表，从 1 号点位开始，之后按顺序推进。
- 列表／编号／名称改选会停止旧讲解；跟随框、当前项和放大窗同步切换。
- 1×／2×／4×数字裁剪，右上放大窗与右侧／右下细节列表。
- 图片、上传视频、电脑摄像头输入；视频／摄像头使用本地 OpenCV ORB + RANSAC 单应性定位。
- 可选的合成移动演示，其已知变换与真实 OpenCV 测量分开标识。
- Gemini 文本问答、Live 音频输入输出；浏览器语音回退明确标记。
- 朗读字幕按完整句子显示；Live 文字片段先缓冲，整句依次展示，结束时保留无标点的最后一句；暂停、切点与语音打断会清理旧字幕队列。浏览器语音也逐句显示。
- 播放倍速 0.75×／1×／1.25×／1.5×／1.75×／2×，讲解区始终显示当前值，设置中也可预先选择。点击改变当前音频与后续队列，字幕队列和播放结束时间同时调整。Live 支持中英文语音调速工具；起声打断后调速，会尝试从当前句恢复导览。
- 中英界面与讲解翻译，翻译保留点位 ID、编号、框区域、来源和已选点位。
- 明确可选的离线演示；真实 Gemini 出错不会自动替换成预设识别。

最新设备状态：用户已取得 Meta Ray-Ban Display，在 iPhone 的 Meta AI App 中完成配对并开启 Developer Mode。截图显示 Meta AI App 299.0.0.26.159、DAT SDK 1.0.0.0，Web apps 添加入口已确认可见。眼镜端运行与光学现实对齐仍未验证，以上仍是 Simulator MVP 的实现和验证范围。

## 2. 启动

需要 Node.js 22+，本机已使用 Node 24.22.3。

```bash
npm ci --registry=https://registry.npmjs.org
npm run build
npm start
```

或者使用 `npm run dev` 一次构建后启动本地服务。当前不是热更新开发服务器；修改前端后需要重新构建，修改后端后需要重新启动。

打开 **http://127.0.0.1:4173/**。应在安装插件的 Google Chrome 中操作，再点击 Meta Ray-Ban Display Simulator 图标。项目标记了 `mrbd-web-app-capable`，采用官方 Meta UI Toolkit 的应用根与控件。

默认只绑定本机回环地址，不自动部署到公网。

## 3. 密钥与模型

`.env.example` 是无密钥模板；实际配置在被 Git 忽略的 `.env.local`。已有 `.env.local` 不要被模板覆盖。

```dotenv
GEMINI_API_KEY=在本机填入
GEMINI_MODEL=gemini-3.8-flash
GEMINI_LIVE_MODEL=gemini-2.5-flash-native-audio-preview-12-2025
PORT=4173
```

后端每次读取 REST 配置时重新检查本地文件；更换 Live 模型后需要重新建立语音会话。密钥不发送给浏览器、不写入前端包、不通过 `/api/config` 返回。

本次最初使用的 `gemini-2.5-flash` 被 Google 返回 404，提示已不再向新用户提供，并推荐 `gemini-3.8-flash`。默认视觉模型据此调整，随后真实图像识别成功。Live 旧名称在本次账户中仍成功接入；未来应以账户实际可用性为准。

## 4. 推荐的第一次演示

1. 打开本地地址，在设置中手动选择“使用内置梵高作品”，确认 Gemini 已就绪。以下为参考图片演示；默认实时眼镜相机流程仍需 iOS DAT 接入。
2. 需要中文时，先点右下角“中”；否则默认英文。
3. 点击 **Begin your visit／开始导览**，等实际 Gemini 完成图像分析。首次分析耗时不能当作视频帧率。
4. 听通识介绍，或点击“进入细节”跳过；列表随后自动出现并从 1 号开始。
5. 点击列表第 3 个点，或在底部输入“讲第 3 个”；观察高亮、框和内容切换。
6. 点击 2×／4×观察局部画面；设置里可启用“模拟头部移动”，该效果明确是合成运动。
7. 在底部输入背景问题，查看回答；来源按钮显示馆方链接。
8. 点击麦克风，授权电脑麦克风后测试 Live 问答与打断。建议耳机减少回声。首次启用麦克风会先暂停当前讲解，之后可保持监听并点击继续测试起声打断。
9. 设置里上传实际移动视频，或使用电脑摄像头，验证真实图像追踪。模拟器 Webcam 环境背景不等于应用输入，请使用应用设置中的摄像头入口。

没有密钥／额度时，可以显式点击 **Explore offline demo／体验离线演示**。它使用准备好的三个点位和浏览器语音，不代表自动 AI 发现已通过。

## 5. 操作

| 操作 | 方式 |
|---|---|
| 选点 | 列表确认、方向键 + Enter、数字键 1–9、输入“讲第 3 个” |
| 暂停／继续 | 播放按钮，或输入“暂停／继续”“pause／continue” |
| 下一点 | “下一个细节／Next detail”按钮或文字命令 |
| 放大 | 1×／2×／4×按钮，或输入“放大两倍”“4x” |
| 播放倍速 | 讲解标题右侧的“倍速／Speed”下拉菜单，或设置中的“语音播放倍速”；支持 0.75×、1×、1.25×、1.5×、1.75×、2× |
| 语音调速 | 开启麦克风后说“调到一点五倍速”“慢一点”“恢复正常语速”，或 “set playback speed to 1.5”, “speak slower”, “normal speed”；同类文字指令也支持，画面放大与语速分别处理 |
| 中英切换 | 设置中选语言；活动导览通过翻译接口保持编号和区域 |
| 来源 | 讲解区的 ⓘ 按钮 |
| 输入 | 设置中上传图片／视频或打开电脑摄像头 |
| 仅叠加界面 | 设置中开启；用于配合模拟器环境背景，不代表真实光学对齐 |
| 结束 | 设置中的“结束导览” |

## 7. 已知限制

当前 Live PCM 使用 Web Audio `playbackRate` 基础变速，会同时改变音高，尚未加入保音高时间拉伸；[Web Audio 接口说明](https://developer.mozilla.org/en-US/docs/Web/API/AudioBufferSourceNode)描述了这一行为。0.75×–2×调速的播放队列、字幕队列和结束时间已用受控时钟与音频节点替身验证，未把这些测试算作实际听感验收。浏览器语音通过朗读引擎的 `rate` 调节，运行中更改会从最近一次词边界重新发声；引擎未提供词边界时，从当前句开始。

手动暂停／切点时，如果云端仍在生成讲解，会自动重建 Live 连接并恢复作品、点位与来源上下文，不再等待旧会话的中断确认。重连有短暂延迟，旧会话的逐字聊天历史不保留。正常讲解结束后自动进入下一点无需重连。麦克风起声仍使用 Gemini 的自动 VAD；收到语音中断事件后仅清理本地播放与自动导览，不将同一事件再作为手动中断发回云端。

- 当前仅内置一幅画；上传其他作品可进行画面分析，但没有预先核查的历史资料时只允许谨慎视觉描述。
- 模型返回的细节区域是候选，几何算法负责后续跟随；未对多作品检测准确率做统计验收。
- 2×／4×是数字裁剪，不恢复缺失图像细节。当前局部窗使用实时输入裁剪，未实现完整透视矫正后的高清重采样。
- 当前追踪引擎是约 13 MB 的本地懒加载资源，适用于电脑原型，不能据此声称满足实体眼镜的启动／内存预算。
- Live 失败时会明确提示，讲解可用浏览器语音，文字问答仍可单独使用；不把该回退称作 Gemini Live 已通过。
- 当活动输入暂时无法定位所选点位时隐藏框并暂停，用户重新对准后点继续。
- 真实世界框的校准与 DAT 显示层仍须在取得眼镜后单独实现与验证。
